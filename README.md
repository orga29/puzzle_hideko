# puzzle_hideko

Streamlitで遊べる15パズルのWebアプリです。

## 概要

15パズルは、4x4の盤面に1から15までのタイルと1つの空きマスを置き、空きマスに隣り合うタイルをスライドさせながら、数字を順番にそろえるパズルです。

このアプリでは、ブラウザ上で15パズルを遊べるようにしています。PythonのStreamlitで画面を公開し、ゲーム本体の操作や演出はHTML/CSS/JavaScriptで実装しています。

## 主な機能

- 4x4の15パズル
- タップ、クリック、スワイプによるタイル移動
- シャッフルとリセット
- 移動回数の表示
- ヒント機能
- 効果音のON/OFF
- クリア時の紙吹雪、ファンファーレ、祝福メッセージ表示
- スマートフォンでも遊びやすいレイアウト調整

## 遊び方

1. `シャッフル` ボタンで盤面を混ぜます。
2. 空きマスに隣り合うタイルを動かします。
3. タイルを `1, 2, 3, ... 15` の順番に並べ、空きマスを右下に戻すとクリアです。
4. 困ったときは `ヒント` ボタンで次に動かすタイルを確認できます。

## 実行方法

```bash
pip install -r requirements.txt
streamlit run puzzle15.py
```

## 15パズルの歴史的背景

15パズルは19世紀後半に広まった古典的なスライディングパズルです。一般にはアメリカのパズル作家サム・ロイドの名前と結びつけられることがありますが、現在ではニューヨーク州カナストータの郵便局長だったノイズ・パーマー・チャップマンが初期の考案者として知られています。

1880年ごろには、15パズルはアメリカやヨーロッパで大流行しました。特に、14と15のタイルだけを入れ替えた配置を解けるかどうかという話題は有名です。この配置は通常のルールでは解けないため、15パズルは単なる遊びとしてだけでなく、置換や偶奇性といった数学的な性質を考える題材としても扱われてきました。

このアプリは、その古典的な15パズルを、Webブラウザで気軽に遊べる形にしたものです。
